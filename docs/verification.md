## 확인한 사용자 흐름

1. 실제 자녀 나이를 입력하기 전 조회를 막고, 21세 자녀를 성인으로 계산.
2. 가능한 기간 2027-05-07~20, 희망 10박에서 기준 일정을 선택.
3. 성인 4명·자녀 2명, 개인 취향·보행 부담·유모차·공통 휴양/액티비티·총예산·객실 수 입력.
4. 추천에서 나트랑 선택, 11일 일정·도착/귀국 칸·야간 관광 확인.
5. 고정한 휴식 칸이 재최적화 후 유지되고 음식 종류·디저트 선택이 저장됨.
6. 조식 끄기·기상시간 변경이 시간표에 반영됨.
7. 숙소 수준·객실 수·항공 선호 변경. 외부 검색 URL에 실제 인원과 자녀 나이를 전달.
8. 예약 완료를 체크하지 않은 상태에서도 계획 저장. 새로고침 후 유지.
9. JSON 내려받기에 일정·조건·설정이 함께 포함됨.
10. 같은 지역에 다른 날짜의 초안을 만든 뒤에도 원래 저장 계획의 일정·고정 칸·식사·조식 설정이 복원됨.
11. 출처 화면에 확인한 5권역·10장소와 10개 원문 링크 표시.

전체 흐름에서 가로 넘침·브라우저 런타임 오류·콘솔 오류가 없었고 외부 API 요청은 없었습니다.
실제 예약·결제·공급자 사이트 검색 결과는 테스트하지 않았습니다.

## 자료 범위

이름·좌표 확인 자료는 5권역+10장소입니다. 이 수치는 전체 추천 자료를 검증했다는 의미가 아닙니다.
기존 164권역 및 AI 보조 자료의 이용 조건·정체성·현장 정보 검수는 남아 있습니다.
청결 세부평점·객실 정원·실시간 항공/숙박 가격·실제 영업/이동시간은 확정 정보로 보장하지 않습니다.

추가 검증: 간편 동행·접힌 추가 설정, 음식 종류 필터·검색·8개 후보·출처 확인, 좌표 미확인 식당 자동 배치 방지, 출처를 확인한 도시 중심의 거리 계산, 식당 데이터 SQLite/JSON 적재를 확인했습니다.

운영 배포 전 보완: 예전 일정 키의 날짜·조건이 같은 경우 기존 고정 칸을 보존하는 마이그레이션을 검증했습니다. 다른 강도·날짜의 초안에는 적용하지 않습니다.
