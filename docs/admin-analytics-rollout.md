# 트립플립 관리자 개편과 선택형 이용 분석

## 즉시 확인할 수 있는 관리자 기능
- 기존 관리자 키(서버 비밀값), 데이터 저장소, 일반 회원 로그인 방식은 그대로다.
- 관리자 키를 브라우저에 영구 저장하지 않는다. 예전 저장값은 관리자 화면을 열 때 제거한다.
- 한국 시간 기준 최근 7/30/90일 또는 날짜 직접 선택. 최대 최근 365일 조회.
- 회원 상세에 기존 공급자 종류, 검증된 이메일의 일부만 표시한다. 이메일 원문, 인증 식별자·토큰, 전화번호, 결제 정보는 새로 수집하거나 표시하지 않는다.

## 출시 전 확인이 필요한 선택 기능
- `MEMBER_ANALYTICS`가 비어 있거나 1이 아니면 **신규 개인별 분석 기록은 쓰지 않는다**. 실제 사용자 데이터로 테스트하지 않는다.
- 분석은 서비스 개선 목적이다. 개인정보처리방침 변경 고지 및 운영자 검토 후에만 활성화한다. 현행 방침의 ‘변경 안내’에서 정한 기간을 지킨다. 고지문 문안과 시행일을 확정하지 않은 상태에서 수집을 켜지 않는다.
- 활성화 후에도 계정별 명시적 동의 전에는 기록하지 않는다. 회원은 내 계정에서 분석 참여를 철회하고 이 분석 기록을 즉시 지울 수 있다. 탈퇴하면 남은 분석 데이터도 삭제한다. 90일이 지난 기록은 자동 정리한다. 기존 서비스 제공용 데이터와 기존 기기 집계는 별개다.
- 성공한 소셜 로그인 시각/공급자, 화면 접속 시각, 버튼·링크 클릭 횟수, 포그라운드 활동 시간 추정치, 서버가 신규 저장을 받아들인 횟수, 예약 링크 클릭 유형/시각만 기록한다. 입력한 내용, 브라우저 URL 파라미터, 외부 사이트 활동은 기록하지 않는다.
- 활동 시간은 최대 60초 내 입력이 있는 가시 탭에서 15초 단위로 추정한다. 단일 계정의 겹치는 창/기기는 샘플을 합친다. 짧은 방문이나 오프라인 기록은 빠질 수 있다.
- 외부 사이트 도착·열람·구매는 추적하지 않는다. 예약 전환 확인에는 별도 제휴 리포트와 적절한 정책 검토가 필요하다.
- 과거 로그인/클릭/체류 기록을 추정해서 소급 채우지 않는다. 기록이 없으면 상세 화면에서 상태 또는 집계 시작일을 표시한다.

## 검토용 고지 문안 초안 (아직 게시하지 않음)
> 이용 분석 참여는 선택 사항입니다. 동의한 계정에서 성공한 소셜 로그인 시각과 인증 공급자, 화면 접속 시각, 버튼·링크 클릭 횟수, 앱이 화면에 보일 때의 활동 시간 추정치, 새 여행 저장 확인 및 외부 예약 링크 클릭을 서비스 개선에 사용합니다. 이 분석 기록은 최대 90일 동안 유지하며, 내 계정에서 동의를 철회하면 이 기록을 삭제합니다. 참여를 거절하거나 철회해도 추천·일정·예약 링크 등 기존 기능은 이용할 수 있습니다. 외부 사이트에서 확인하거나 구매한 항목은 수집하지 않습니다.

## 배포 순서
1. 기존 Cloudflare 비밀키와 Durable Object `Stats` 바인딩을 유지하고 Stats Worker 코드만 먼저 배포한다. 수집 플래그는 끈 상태에서 배포한다.
2. Pages 관리자 화면을 배포하고 기간·회원 조회, 범위 오류, 무인증 401을 확인한다. 이전 Worker와 이전 Pages의 기본 7/30/90일 조회 계약은 유지한다.
3. 별도 검토 후 승인된 안내와 시행일을 공개하고, 고지 기간이 끝난 뒤에만 플래그를 켠다. 수집을 긴급 중단하더라도 기존 참여자의 철회·삭제는 가능해야 한다.
