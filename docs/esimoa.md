# 이심모아 예약 링크
- 트립플립의 권역 예약 탭과 항공·숙소 비교 화면에서 이심모아로 연결합니다. 확인된 국가 경로가 없으면 한국어 국가 선택 화면으로 보냅니다.
- 제휴 링크에는 운영자가 제공한 공개 파트너 코드(`ref`)만 넣습니다. 사용자 식별자·일정·인원은 전달하지 않습니다. 노출·구매 실적은 이심모아 파트너 대시보드에서 확인합니다. 트립플립에서 결제하거나 주문을 생성하지 않습니다.
- 이번에는 API, MCP, 주문 및 유심 배송 연동을 사용하지 않습니다. 키는 저장소·브라우저에 두지 않습니다.
- 출처: [이심모아 개발자 센터](https://www.esimoa.com/ko/developers), [이심모아 국가별 요금제](https://www.esimoa.com/ko). 공식 경로와 추적 파라미터 확인일은 2026-11-27입니다.
