# 식당 데이터와 선택 화면 개선 · 2026-11-04

## 결과

무료 공개 가이드 Wikivoyage에서 식당 105곳·카페 12곳, 총 117곳을 추출했습니다. 권역별 수는 나트랑 17, 다낭 35, 푸꾸옥 6, 홍콩 48, 오사카 11곳입니다. 기존 후보와 겹치는 업체는 선택 목록에서 이름 기준 중복을 제거하므로 117곳이 모두 순증한 수치는 아닙니다.

좌표가 있는 78곳만 자동 동선 후보로 사용합니다. 나머지 39곳은 기재된 주소만 보존하고 위치 확인이 필요하다고 표시합니다. 도시 좌표를 식당 좌표로 대신 넣지 않습니다. 가이드 등록은 현재 영업·실제 메뉴·가격·가족 편의시설의 확인을 뜻하지 않습니다.

## 출처와 무료 원칙

원문 응답, 리비전, 실제 조회 시각과 SHA256을 data/imports/sources/wikivoyage에 보존했습니다. 출처명과 원문 리비전 링크를 후보 상세에 표시하고 CC BY-SA 4.0 이용 조건을 적용했습니다. public/dining/catalog.json으로 자료와 출처를 내려받을 수 있습니다.

이름·주소·기재 좌표만 추출했습니다. 가이드 설명을 복제해 맛집 후기나 별점으로 만들지 않았습니다. 음식 종류는 설명의 단어를 바탕으로 한 분류이며 미확인은 그대로 둡니다. 개별 식당의 영업·아기의자·키즈메뉴·가격·평점은 채우지 않았습니다.

python 표준 라이브러리만으로 SQLite와 정적 JSON을 재생성합니다. 앱 조회마다 유료 AI나 외부 데이터 API를 호출하지 않습니다. OSM 공개 서버 조회는 실패하거나 범위 내 결과가 없어 이번 발행 자료에 사용하지 않았습니다.

## 화면

첫 화면의 가족 구성원 카드를 설정창으로 옮기고 동행 간편 선택과 인원 요약을 제공합니다. 개인 취향·보행·유모차 설정은 유지합니다. 객실 수·지역 물가·반려동물은 추가 설정으로 접었습니다.

일정의 일별 컨디션·날씨·음식 종류도 하루 설정으로 접었습니다. 식당 선택창은 종류 필터와 검색, 최대 8개 후보로 시작하고 더 보기로 펼칩니다. 식당에 근거 없는 가족 등급이나 품질 별점을 붙이지 않습니다. 후보의 거리 기준이 일정 장소인지 도시 거점인지 구분하고, 세부 출처는 펼쳐 확인합니다.

기존 나트랑 중심 좌표가 시내에서 벗어나 있던 문제도 수정했습니다. 출처를 확인한 권역 좌표를 우선 사용해 시내 식당까지의 거리를 계산합니다. 이 값은 실제 도로 이동시간이 아닙니다.

기존 저장 일정은 그대로 읽을 수 있습니다. 새 후보는 선택창에 즉시 표시되며, 자동 일정을 갱신하려면 일정 다시 추천을 누릅니다. 고정한 칸은 유지합니다.
